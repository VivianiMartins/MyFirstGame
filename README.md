# MyFirstGame - Connect Four

Este foi o primeiro jogo que desenvolvi durante o 2º semestre do curso de Ciência da Computação, para a disciplina de **Laboratório de Programação**. O projeto é uma recriação em 2D do clássico jogo de estratégia **Connect 4**.

---

## Sobre o Jogo

O objetivo do jogo é alinhar quatro peças da mesma cor (horizontalmente, verticalmente ou na diagonal) em um tabuleiro quadriculado antes do adversário. 

* **Mecanica de Jogo:** Lógica clássica de conexão e alternância de turnos.
* **Interface Gráfica:** Desenvolvida com elementos visuais simples em 2D e suporte a interações do jogador.

## Tecnologias Utilizadas

* **Engine:** [AppGameKit (AGK)](https://www.appgamekit.com/)
* **Linguagem:** AGK Script / C-like language
